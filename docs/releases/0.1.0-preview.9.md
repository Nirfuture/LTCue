# 0.1.0-preview.9 配布前の確認記録

## 構成

- ProgramPlaybackのスケジュール・フレーム選択を画面内同期プレビューと外部出力で共用。IProgramPresentationで画面内の描画先を分離し、外部ウィンドウを作らずに同期プレビューできる。
- プレビューと本番出力の切り替えは処理終了を待ってから行い、同じ映像HWNDへの同時描画を避ける。ファイル解析キャッシュはウィンドウ内で最大2ファイルを保持する。
- 外部出力の有無にかかわらずLTC優先。LTC未受信・ロスト中は手動確認でき、受信再開で同期へ戻る。外部出力の開始・停止時はLTC現在位置、または手動再生のキュー・位置・保持状態を引き継ぐ。
- 蓋画はPNG・JPEGのパスを設定に保存。起動時の読み込み失敗・未登録は黒。画像の比率を保ち、余白・透過部分は黒にする。
- CoverControllerが単調時計によるフェード量を管理。途中反転は現在値から連続して遷移し、0秒は即時。画像パスとフェード時間を保存し、蓋画オン状態は起動時にリセットする。
- GPU上の独立した合成先へ元映像と蓋画を合成する。元映像を保持し、停止中の再描画でも合成が累積しない。本番モニターへも同じ合成結果を表示する。
- フェードは映像のみ。確認再生の音声には作用しない。LTC同期プレビューは無音。

## 確認

新機能の14項目で、画像読み込み、既存設定の初期値、フェード反転・即時切り替え、GPU合成の両端・中間値・非累積性・アスペクト保持・黒フォールバックを確認。

LTCによる確認再生の割り込み、ロスト保持、再受信、蓋画中の再生継続、出力開始時の現在位置、蓋画解除時の現在映像、外部出力停止後の同期継続、縦長リサイズ、手動再生位置の双方向引き継ぎ、設定保存を確認。

実画面で蓋画・フェード操作とLTC同期プレビューの表示を確認。試験は小さい外部出力ウィンドウを使用。

関連82項目すべて通過：新機能14、手動出力8、表示方式6、出力操作9、UI更新11、再生12、レスポンシブ8、キューUX5、モニター復帰2、同期エンジン7。

## 制約・未確認

- 表示先を切り替える際は描画資源を作り直すため、完全な無瞬断切り替えを保証しない。
- 蓋画は外部画像への参照。登録後に画像を移動・削除した場合は登録し直す必要がある。動画の蓋画・動画間のクロスフェード・音声フェードは含まない。
- 蓋画は読み込み時に幅2048を基準にデコードし、幅・高さ8192、総画素数16777216を上限としてチェックする。
- 各種DPI・高解像度の長時間連続稼働・他の環境・物理同期精度は未確認。
- 標準方式の全画面でPC全体が停止した環境があるため、その条件は再実行していない。[preview.5](0.1.0-preview.5.md)を参照。
- 未署名。旧単体再生エンジンのPTS整合試験は保留。
