# 0.1.0-preview.5 配布前の確認記録

## 変更

- 設定に「表示方式」を追加。標準（Flip）と互換（BitBlt）を選択・保存。
- 旧設定は標準方式として読み込み。無効な方式は拒否。
- 設定画面に適用中の方式、メイン画面に現在の出力方式を表示。
- 出力中は方式を変更できない。
- ログにも出力方式を記録し、ネイティブ描画処理から取得した方式と照合。

全PCを互換方式に切り替える実装や、特定の機種・GPUに固定した分岐は追加していません。

## 検証

設定の互換性、両方式の保存・再読込、無効値の拒否、設定ダイアログの選択と適用中表示、出力中の変更禁止、実描画方式・ログ・メイン画面表示の一致を確認しました。

標準方式の全画面出力でPC全体が停止した環境があるため、設定組み込み後の両方式の描画確認は小さい出力ウィンドウで行っています。

互換経路の候補版では、同じ環境の1080×1920全画面、実LTC受信中の開始、画面内モニター有効、動画途中からの開始・切り替え・停止を1回確認済みです。設定組み込み後の版で、全画面試験を追加実行したわけではありません。

追加6項目、同期回復7条件、出力操作9件、UI11件、プレビュー・編集12件の計45件を通過。設定画面とメイン画面の表示も実画面で確認しています。

## 残る確認

- 互換方式による物理表示遅延の差は未測定。
- 全画面停止の根本原因は未確定。1回の候補版成功で完全解消とはしていません。
- 他の環境・長時間運用・物理ディスプレイ上の同期精度は未確認。
- 未署名。Smart App Controlが有効な環境では起動をブロックされる場合があります。
- 旧単体再生エンジンのPTS整合試験は、[前版までの確認記録](0.1.0-preview.2.md)のとおり保留。
