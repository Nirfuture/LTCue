# 0.1.0-preview.6 配布前の確認記録

## 変更

- メイン画面の最小幅を480、最小高さを420へ変更。
- 幅が狭い場合、または高さが低い場合は動画一覧とプレビューを縦に配置。全体をスクロールして下部の操作へ到達できる構成。
- 動画一覧は独立したスクロールを保ち、列の横スクロールも使用可能。
- メイン画面・設定画面を別ディスプレイへ移した際、移動先の作業領域と拡大率に合わせて調整。
- 設定画面を可変サイズにし、項目をスクロールしながら適用・キャンセルを常に操作できる構成。
- 新規設定のLTC補間時間を0.1秒へ変更。保存済み0.5秒などの指定は変更しない。

## 検証対象

1640×940、700×1100、800×600、1640×500、480×420の各ウィンドウ寸法、420×420の設定画面、実際の1080×1920縦向きディスプレイへの移動を確認。

関連する53件の確認が通過（画面配置8、表示方式6、クロック等7、出力操作9、UI更新11、再生12）。縦横のレイアウト切り替え中も再生と音声セッションが維持されることを確認。

## 残る確認

- 各種DPI・解像度・タスクバー位置の全組み合わせは未確認。
- 表示方式の物理表示遅延差、他の環境、長時間運用、物理的な同期精度は未確認。
- 標準方式の全画面でPC全体が停止した環境があるため、その条件は再実行していません。表示方式の検証経緯は[preview.5の記録](0.1.0-preview.5.md)を参照してください。
- 未署名。Smart App Control有効環境でブロックされる場合があります。
- 旧単体再生エンジンのPTS整合試験は引き続き保留。
