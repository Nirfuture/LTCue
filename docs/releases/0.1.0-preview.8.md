# 0.1.0-preview.8 配布前の確認記録

## 変更

- キューの再生・停止・一時停止を文字記号から図形アイコンへ変更。ボタンの縦横中央に配置する。
- TC欄の数字とコロンをConsolas 14、行高20に統一。編集欄の中央揃えを維持。
- ドラッグ中にキューの前後の挿入位置を青い線で表示。境界番号から移動先を計算し、上方向・下方向とも線の位置に挿入する。
- 一覧の上下端近くをドラッグするとスクロール。一覧外へのドロップ、Esc、フォーカス・ポインター捕捉の喪失でキャンセルする。
- 表示順の変更は開始TCと再生スケジュールを変更しない。

## 確認

アイコン中央位置、TC欄のフォント・行高、上下・先頭・末尾への挿入位置、青い線の位置と一覧外での非表示、キューIDと開始TCの維持を確認。実画面でアイコン・TC・青い挿入線を確認し、実際のポインタードラッグで並べ替えを確認した。

関連33件すべて通過：キューUX5、手動出力8、レスポンシブ8、再生12。

## 範囲・未確認

- 出力停止中のLTC同期プレビューは未実装。現行は出力停止中の手動プレビューと、出力中のLTC同期・手動出力。
- 全DPI設定・大量キューの連続スクロール・他の環境・長時間運用は未確認。
- 標準方式の全画面でPC全体が停止した環境があるため、その条件は再実行していない。[preview.5](0.1.0-preview.5.md)を参照。
