# 0.1.0-preview.3 配布前の確認記録

## 主な変更

- ゼロ開始のテスト用LTC音声（29.97 DF、48kHz・16bit・モノラル、65.065秒）を同梱。
- EXEとウィンドウにアプリアイコンを追加。
- 同じWindowsユーザー・セッションでの二重起動を防止。再起動操作で既存ウィンドウを表示。
- 動画の読み込み・再生準備・シークと、編集・配信準備中に状態表示と動くバーを追加。
- 配信モニターの固定サイズ上限を外し、実際のピクセル寸法とサイズ変更に追従。

## 検証

- 同梱WAVをアプリのLTCデコーダーで読み、先頭`00:00:00:00`と1949フレームの連続性、DFの分境界を確認。
- 埋め込みアイコンの読み出しと、ウィンドウ上の表示を確認。
- 起動中に同じEXEを再実行し、2つ目のプロセスが終了コード0で終了することを確認。
- 読み込み・再生準備・シーク中のバー表示、シーク操作の無効化、読み込み失敗時の表示解除と再読み込みを確認。
- GPUモニターを840×472と504×284に変更し、描画領域の寸法と、縦横比を保った最大表示を読み戻しで確認。

- 既存回帰試験: 同期回復7条件、初期キュー3件、配信操作9件、UI11件、プレビュー／編集12件、プレビュー復帰2件を通過。追加5件と合わせて49件を確認。

## 残る確認

- 未署名。Smart App Control有効環境でブロックされる場合があります。
- 物理オーディオ機器経由での同梱LTCの受信、他の環境、長時間運用、物理ディスプレイ上の同期精度は未確認です。
- [前版の確認記録](0.1.0-preview.2.md)にある旧単体再生エンジンのPTS整合試験の失敗は、引き続き保留しています。
- 旧版には二重起動防止機能がないため、旧版と新版の同時起動は防ぎません。

配布物のソースコミットと署名状態はMANIFEST.json・SIGNATURES.jsonに記録します。
