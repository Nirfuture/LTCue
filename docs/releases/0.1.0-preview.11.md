## 自動検証

全自動37スイートを1回実行。その初回では34スイートがPASSし、次の3スイートが失敗した。

- preview-clip：縦画面のない環境でFirstが失敗。外部出力を伴わないレイアウト試験に限定し、縦画面がなければ検証用の1080×1920表示情報を注入。実際のキャンバス・レイアウト・切り取りを検査し、合成条件をJSONへ明記。
- coordinator：音声準備のCancellationTokenをJSON化するとWaitHandleで例外。ランタイムの取り消し情報をJsonIgnoreで診断出力から除外。
- playback-integration：追加したキャンセル試験のキューが後続試験の開始TCと重複。試験用キューを無効化し、finallyで削除して分離。

修正後ビルドでこの3スイートを再実行し、全件PASS。初回の合格分と再試験の合格分を合わせて37スイート・314件。全37スイートを修正後に再度一括実行したという意味ではない。最初の失敗結果も保持している。

新規の回帰確認は、読込中の停止で前の動画が再生されないことと、非ゼロLTC補正下でも正常な同期表示になることを含む。
