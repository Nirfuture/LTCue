# 0.1.0-preview.7 配布前の確認記録

## 変更

- 出力中のキューを緑色で表示。選択行とは独立し、停止フレーム保持中も実際の出力キューを示す。
- 出力モニターの15fps制限を解除。GPU完了ポーリング・待機なしPresent・表示待ち1枚の上限は維持し、再描画の上限は120回/秒。
- 出力中、LTC未受信またはLOSTなら有効なキューの「確認」▶で先頭から手動再生できる。準備完了後の最初のフレームから時間を進める。
- ■および動画終端では映像を保持。LTC受信再開を優先して同期出力へ戻す。FREEWHEEL・受信中・入力ERROR中は手動操作不可。
- 出力中の一覧選択は可能とし、TC・有効無効・追加削除などの編集はロック。
- 検証用ビルドは通常アプリと別の単一起動枠を使い、利用中アプリを閉じずに試験可能。配布版の二重起動禁止は維持。

## 確認

関連50件が通過：手動出力8、出力操作9、UI更新11、再生12、モニター復帰2、レスポンシブ8。

手動出力では未受信開始、独立したハイライト、旧15fps上限を超えるモニター更新、停止保持・再スタート、LTC受信優先、ロスト後の再操作、動画終端保持、出力停止・再開時の状態初期化を確認。実画面でも選択中の出力行が緑色で表示されることを確認。

試験は小さい出力ウィンドウを使用。モニター表示回数は更新の確認であり、素材の全フレーム表示や物理同期精度を保証しない。他の環境・高fps素材・長時間運用は未確認。
