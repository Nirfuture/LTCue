# 配布方針

Windows用アプリは、GitHub Releasesで未署名のZIPとして配布します。

## 配布ファイル

- 実行用ZIP
- 対応するソースコードのZIP
- ハッシュとビルド情報
- リリースノート

配布物は公開するコミットから作成し、バージョンごとに`releases/`へ保存します。作成・確認・アップロードの手順は[リリース作成](RELEASING.md)を参照してください。

## 起動時の制約

未署名のため、Smart App Controlが有効なWindows 11では起動をブロックされる場合があります。この制約はリリースノートと[トラブルシューティング](TROUBLESHOOTING.md)に記載します。
