# キューリストの解像度表示 実装指示書

## 目的

映像素材の解像度をキューリストで確認できるようにする。既存の「形式」列にコーデックと解像度を1行で表示し、列ヘッダーのメニューボタンから表示方法と解像度プリセットを設定する。シンプルな表示を優先し、p/i は対象外とする。

## 列ヘッダーとセル

- 「形式」ヘッダーの右端に、開始TCと同じ横三点のメニューボタンを置く。UI案の下向き三角は、実装では開始TCのボタンに合わせる。
- 開始TCのボタンと配置、余白、最小サイズ、テーマ色、ホバー・フォーカス表示を揃える。アクセシブル名は「形式の表示設定」とする。
- セルは1行で、表示モードごとに固定幅とする。実寸モードには、通常の実寸表記を収められる広めの固定幅を割り当てる。行の内容やプリセット名の長さでは列幅を変更しない。収まらない文字列は末尾を省略する。
- 実寸が取得できているセルのツールチップには、全モードでコーデックと幅×高さを表示する。実寸未取得時はコーデックだけを表示する。

| 表示モード | 1920×1080 の例 | 1980×1080 の例 |
|---|---|---|
| プリセット名（初期値） | `HAP · FHD` | `HAP · 未登録` |
| 実寸 | `HAP · 1920×1080` | `HAP · 1980×1080` |
| 非表示 | `HAP` | `HAP` |

幅または高さが取得できていない場合は、プリセット名・実寸モードでもコーデックだけを表示する。コーデックも空の場合は、利用できる値だけを表示し、不要な区切り文字を出さない。

## ポップアップ

- ボタンに紐づくポップアップに「解像度の表示」とプリセット編集欄を置く。表示モードは「プリセット名」「実寸」「非表示」から選べるようにする。
- プリセットは「幅 × 高さ（px）」と「表示名」の組み合わせ。表示名は解像度の略称や任意の名称を指す。
- 初期プリセットは `1280×720 → HD`、`1920×1080 → FHD`、`3840×2160 → UHD`。幅と高さの両方が完全一致したときに適用し、縦横は区別する。
- 既存行の編集、追加、削除を可能にする。幅・高さは正の整数、表示名は前後の空白を除いて1～8文字とする。同じ幅と高さの組み合わせが重複する場合は、該当行が分かるエラーを表示する。
- 「適用」で表示モードとプリセットをまとめて保存し、表示中の全行に即時反映する。入力エラーや保存失敗時はポップアップを開いたままにし、適用済みの設定を維持する。閉じる操作や Esc では編集途中の変更を破棄し、ヘッダーボタンへフォーカスを戻す。
- 設定はキューリスト全体に適用するアプリ設定として保存し、アプリ再起動後も復元する。旧設定に項目がない場合は初期値を使い、利用者がプリセットをすべて削除した場合は空の一覧を保存する。

## 実装箇所と注意点

- `src/LtcPlayer.Avalonia/MainWindow.axaml` の「形式」列と `TimecodeColumnHeader` を参照する。表示設定ボタンの開閉と適用処理は、開始TC編集のハンドラーから独立させる。開始TCのメニュー内容と有効条件は現行どおりとする。
- `src/LtcPlayer.App/CueProgram.cs` の `CueRow.PixelWidth` / `PixelHeight` と `Codec` を使う。素材の追加・差し替え・再解析で値が変わる経路を確認し、必要な変更通知を追加する。設定変更後に追加した行にも現在の表示設定を適用する。
- 設定の読み書きは既存のアプリ設定経路を確認し、保存時に他の設定が失われないようにする。解像度表示のためにキューファイルの形式や映像の再生処理を変更する必要はない。

## 受け入れ確認

1. 開始TCと形式のヘッダーボタンを並べて確認する。三点の形、配置、サイズ、ホバー・フォーカス状態が揃い、各ボタンから対応するメニューが開く。
2. 初期状態で 1920×1080 は「FHD」、1980×1080 は「未登録」と表示される。未登録の素材、縦素材、長い表示名が混在しても同じモード内では列幅と行高が変わらない。
3. 1980×1080 を「LED」で登録して適用すると該当行が `HAP · LED` に変わる。削除して適用すると「未登録」に戻る。ツールチップには全モードで実寸が出る。
4. 実寸・非表示に切り替え、一覧に設定が反映される。素材の差し替えや再解析で解像度が変わると、該当セルとツールチップも更新される。解像度が未取得の行に「未登録」は出ない。
5. 不正寸法・重複寸法・空の表示名はエラーになる。閉じる操作と Esc で下書きを破棄できる。再起動後は最後に適用した表示モードとプリセットが復元される。
