# 最終工程前・第1段階：設定適用と未接続出力の修正

2026-11-11

## 実装

- 未接続の映像出力先を設定パネルに「未接続」として保持。先頭の接続済み画面へ自動選択しない。
- 映像出力先が未接続・未選択でも、LTC入力・音声出力先・表示方式を適用可能。別の映像出力先を明示選択した場合は、接続状態・寸法・位置を検証する。
- 新しいGPUキャンバスと子ウィンドウは、現在の表示を残したまま準備する。設定保存が成功するまで切り替えず、失敗した候補は破棄する。
- 設定JSONは同一ディレクトリ内の一意な一時ファイルへ書き、置換を保存の確定点とする。失敗時は一時ファイルを削除する。
- 入力切替後に失敗した場合は旧入力設定と元のMasterClockを使って入力を復旧する。復旧自体も失敗した場合は両方のエラーを通知する。
- 蓋画・フェード・選択画面・設定の値は保存成功後に反映。フェード欄への反映で途中保存が再入しないようにする。
- 適用中の再入を拒否。音声だけの変更では映像キャンバス・LTC入力を作り直さない。

主な変更：MainWindow.Delivery.cs、Dialogs.cs、PreviewHost.cs、LtcMonitorService.cs、MainWindow.Presentation.cs、SettingsRepository.cs、SettingsApplyVerification.cs。
