# 配布前レビュー 0.1.0-preview.1

対象: Windows 11 x64の限定検証配布。正式運用・全機種保証の判定ではない。GitHubへのアップロードは未実施。

## 実施した点検
配信/停止の状態遷移、確認取消・承認、準備失敗と再配信、プレビュー音声/FFmpegの終了、GPU表示先の寿命、動画/JSONの入力境界、設定保存、依存関係、ライセンス、公開ファイルの選別をレビューした。

## 修正・整理
| 項目 | 対応 |
|---|---|
| 診断ログの無制限増大 | 10Hz・8MiB/セッション、256MiB以上で新セッション記録抑止。古いログは自動削除しない |
| 診断ログのディスクI/O失敗で本番停止 | 診断系のI/O例外を分離。書込みできなくても本番を停止しない。専用障害試験を追加 |
| .NET8サポート終了 | .NET10.0.14ランタイム同梱へ移行。SDK10.0.403を固定し、元の.NET8版を別保存 |
| 製品に検証コードが混在 | 製品では検証クラスをコンパイル除外。検証版のみEnableVerification=true |
| 開発環境依存 | ソリューション、ソースからのnativeビルド、NuGetロック、素材生成/試験スクリプトを整理 |
| ライセンス境界が不明確 | 自作部分MIT、libltcを含むAudioNative.dllと対応ソースLGPL。原文/著作権表示/対応ソースを添付 |
| 個人データ公開 | 実機設定、ログ、中間生成物、作業用バイナリを公開ソースから除外。PDBのビルドパスをマッピング |

外部プロセスは引数配列で起動し、シェル経由で動画名を実行しない。キャンセル時は所有するFFmpeg子プロセスを終了する。アプリから動画原本へ書き込む経路は設けていない。上演保存は利用者の指定先を一時ファイルから置換する。

NuGet公式アドバイザリ照合では、この実行時点で報告対象の既知脆弱性は返らなかった。これは未発見脆弱性や外部FFmpeg/ドライバーまで安全と証明するものではない。

## 残る制約・配布判断
- このPCでの短時間試験。クリーンな他の環境、異なるGPU/音声機器、RDP、ディスプレイ抜き差し、長時間稼働は未保証。
- 物理的LTC→画面の同期精度は未測定。
- 素材のコード上限と実用性能は別。高解像度/巨大素材はメモリ負荷が高く、事前の素材試験が必要。包括的なファジング/侵入試験は行っていない。
- 設定破損時は設定を退避して再設定する。複数インスタンスから同じ設定/上演ファイルを同時保存する運用はしない。
- アプリは未署名。実行制御/SmartScreen等の判断を無効化せず、必要なら配布者が署名と管理者承認を検討する。
- FFmpeg/ffprobeとVC++ x64ランタイムは別途必要。FFmpegを追加同梱する場合はライセンス/対応ソースを別途再確認する。

上記を説明して身内の限定テストへ渡す構成。正式な本番採用判断は、対象PCでの展開確認と運用時間に応じた同期/耐久試験の後に行う。
