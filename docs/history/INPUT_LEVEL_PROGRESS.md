# LTC入力レベル表示

2026-11-11

LTC時刻・受信状態の下に、選択したLTC入力チャンネルのピークメーターとdBFS値を追加した。

- 表示範囲は−60〜0dBFS。小さい値も数値では確認できる。
- 音声サンプル未着・停止は「入力なし」、ゼロのサンプルは「−∞ dBFS」と区別。
- ピークを最大約500ms保持し、瞬間的な大入力を見落としにくくする。サンプルが300ms以上届かなければ古いレベルは表示しない。
- ピークがフルスケールの99%以上になると、バーを橙色にし「上限付近」を表示。波形クリッピングを証明する判定ではない。
- 音量の値だけで受信可能とは断定しない。「LTC受信中」の実際の復号状態と合わせて判断する。
- 既存の入力処理が計算済みのピークを利用。追加の入力機器・音声出力を開かず、サンプルの再走査も行わない。
- 入力変更・エラーでレベルをリセットする。

メーターは軽量な専用描画を使用。Fluentの進捗部品がオフスクリーン描画で隣の文字に重なる問題が見つかったため、専用描画へ変更し、480px幅でも表示を確認した。

LTC入力設定の空IDは従来から「入力未選択」を意味するため、設定の表示も「未選択」に修正した。音声出力の「システム既定」は変更していない。
