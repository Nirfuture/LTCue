# 起動時テスト4本登録仕様 v0.1

2026-11-10、ユーザー指示による配信操作仕様v0.2への追加。Phase 6未着手。

通常起動（上演ファイルの明示指定なし）では、同梱の番号入りHAP動画1〜4を有効なキューとして登録する。

| 動画 | 開始TC |
|---|---|
| HAP_1_1080p_2997_10s.mov | 00:00:05:00 |
| HAP_2_1080p_2997_10s.mov | 00:00:20:00 |
| HAP_3_1080p_2997_10s.mov | 00:00:35:00 |
| HAP_4_1080p_2997_10s.mov | 00:00:50:00 |

各10.01秒/1920×1080/30000÷1001fps。開始はアプリ起動後の経過秒ではなく入力LTC基準。キュー間と開始前は本番黒、各キューの期間中は該当動画を採用する。

起動しただけでは配信しない。配信ボタンからLTC同期送出を開始する。LTC形式は保存済み設定を使用し、設定のない新規起動は29.97 DF。出力先は既存の設定/選択仕様を維持。

4本はアプリのTestMediaフォルダーへビルド時にコピーし、実行フォルダーを基準に読み込む。Downloadsや開発元絶対パスへの実行時依存を作らない。4本の動画情報を確認してからまとめて登録し、欠損時はエラーを表示する。

通常起動ごとにこの4本を初期登録する。--programで上演ファイルを指定した起動はそのファイルを優先。起動後の読込/編集/削除/保存は引き続き可能。保存済み上演データの開始TCは書き換えない。手動で追加する新規キューの既定TC00:00:00:00は別の仕様として維持する。

同一開始TCの有効キューを禁止する規則は維持。禁止理由は配信ボタン直下に表示し、ボタンを薄く表示する。
