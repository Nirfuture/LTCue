# LTC Player プレビュー・シーク・蓋画UIの整理

2026-11-11

## 変更

- シークバーを映像表示領域の直下へ移動。動画名・再生時刻より上に配置した。
- 進捗表示に固定28pxの領域を確保。表示／非表示でレイアウトから出し入れせず、不透明度を切り替える。
- 180ms未満の短い読み込みでは進捗を表示しない。長い処理だけ進捗と説明を表示する。
- 再生情報の行数増加でもプレビューが縮むことを確認したため、詳細を「再生情報」の折りたたみ内へ移動。通常の状態・音声状態は1行に収め、全文はツールチップで参照できるようにした。
- 蓋画の切替ボタンと時間指定を分離。「切替時間」の秒入力に加え、「即時」「0.5秒」「1秒」「2秒」のプリセットを追加した。時間は往復の両方向に適用する。
- 秒入力が空のままフォーカスを離れた場合は、保存済みの値へ戻す。設定保存・0秒即時切替・最大60秒の契約を維持する。
- 新音声経路では、旧プレビュー音声の「Windows既定出力」表示を動画状態へ混ぜない。

計40項目通過。ビルド警告0・エラー0、差分形式チェック通過。レイアウト画像も確認した。画像はAvaloniaのレイアウト描画であり、ネイティブ映像部分は含まない。

表示領域とネイティブホストのBounds、キャンバスIDを、進捗表示前・表示中・完了後で比較した。初回再生および再開時にも寸法が変わらないことを確認した。これは進捗表示に起因する伸縮の修正であり、あらゆる環境で視覚的なちらつきが消えることを保証する測定ではない。

既存機能試験の初回は、子プロセスに検証用の起動区分を付けていなかったため単一起動検証がタイムアウトした。同じ区分で起動するようハーネスを修正し、5項目を再実行して通過した。失敗記録も保持している。

## ビルドと次の工程

確認用製品ビルドは `artifacts/redesign/preview-ui-win-x64/LtcPlayer.Avalonia.exe`。開いている既存アプリを終了したり、既存の配布先を上書きしたりしていない。

次は再生状態・優先権・音声用プレイヘッドの調停をPlaybackCoordinatorへ集約し、MainWindowに残る再生処理を整理する。音声の実機切断、終了競合、実LTC、長時間運転、物理的な映像と出音の遅延測定も残る。
