## 縦リサイズ時の上端移動

右パネルよりキューパネルの高さが短くなったとき、同じグリッド行の中で、明示された高さを持つ左パネルが縦中央へ配置されていた。外側スクロールのOffsetは0のままだったため、スクロール位置の問題ではなかった。

ワークスペース・キューパネル・右パネルの上寄せを明示。右パネルが高くても、左の上端は固定し、リストの下側だけが高さに応じて変わる。

幅1640px固定で高さ940→440→940などを連続変更し、リストにフォーカスがある場合と音量にフォーカスがある場合を検証。修正前は上端が最大188px移動、修正後の24サンプルではすべて移動0px。

修正前：`artifacts/redesign/resize-before/resize.json`

修正後：`artifacts/redesign/queue-final-resize-anchor/resize.json`

## 操作・表示

- ドラッグ用の先頭列を42pxへ拡大。アイコンだけでなく行の高さ全体を透明なヒット領域にした。セルの余白を除き、左右上下の端近くでもつかめる。
- セル単位の選択／フォーカス枠を除去。セルの移動・入力は維持。行全体の選択と再生中の行表示、入力エラーの表示は残した。
- Fluentのアクセント色を青へ固定。チェックボックス操作時の赤は警告の意図ではなく、既定アクセントの反映だった。操作状態のチェックボックスが青になることを描画画像で確認した。表示専用・操作不可のチェックは従来どおり灰色になる場合がある。
