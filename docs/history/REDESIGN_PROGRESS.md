## 測定

進捗表示のみを出現・消失させる試験で、映像領域の高さが299→268→299pxに変化した。
表示状態で31pxのレイアウト変動が発生することを確認。これが全ちらつきの唯一の原因とは結論していない。
Black呼出し、シーク、リサイズ、遮蔽復帰の追加切分けは後続段階へ残る。

同梱1080p HAP素材の手動読込103.6ms、再生準備53.8ms、シーク30.5ms。
単回の初期測定であり、中央値や上位百分位・性能保証値ではない。
大量キュー、低速ログ、GPU使用率の比較は未実施。

## 追加した実装

- RenderSession: 外部ウィンドウから独立したD3D11デバイスと共通合成結果を所有。
- Canvas.inc: 同一デバイスへの外部swap chainの追加・解除。合成結果と復号元を保持。
- 既存モニター描画を再利用し、共通キャンバス使用時は30fps、幅・高さ各1/2以下に制限。
- フレーム・合成・セッションの識別情報を管理。
- 既存製品の描画経路は維持し、新経路は検証版から呼び出す。

## 実行した確認

共通GPUキャンバス7項目PASS:

1. 外部ウィンドウなしでの合成と画素読戻し。
2. 標準FlipのAttach/Detach（50回）でセッション・画像・PTS維持。
3. 互換BitBltのAttach/Detach（50回）でセッション・画像・PTS維持。
4. 縮小プレビューの画素数上限と映像内容。
5. HAP BC1テクスチャを同じキャンバスへ描画。
6. 蓋画50%合成を出力切替で変更しない。
7. 未接続表示先の失敗後もキャンバスを利用可能。

追加回帰: 同期エンジン7条件PASS、レスポンシブ8項目PASS、既存GPUモニター検証exit code 0。
縦向き物理ディスプレイ移動は接続がなく、レスポンシブ試験は寸法ケースで代替した旨を結果へ記録。

検証版ビルド: 0警告・0エラー。使用可能なローカルSDK 10.0.203で実行。
