# LTC Player 音声出力UI・通常経路切替

2026-11-10 / 音声計画 v0.6 段階C/Dの実装記録

## 変更

- 通常起動から新しい共通音声サービスを使用。旧PreviewAudioを開かず、映像は音声消費時計に依存しない。
- メイン画面に「音声出力」ON/OFF・出力先・更新・状態表示を追加。音量・ミュートも共通音声へ接続した。
- 音声は起動時OFF。保存するのは出力先IDと音量。ON状態とミュートは復元しない。
- システム既定を選んだ場合も、ONにした時点のデバイスへ固定。音声ON中は出力先を変更できず、OFFにしてから変更する。未接続の保存先は保持し、別デバイスへ自動で逃がさない。
- 通常経路では映像出力の開始・停止から旧音声抑制を除外。LTC同期中と外部映像出力中も音声操作を表示する。
- 音声の待機・準備・出力・ミュート・再同期・無音／対象外・エラーを区別。エラー後はOFF→ONで明示的に再試行する。
- 旧JSON設定に新しい項目がなくても読み込める。入力・映像の設定適用時にも音声の保存値を維持する。
