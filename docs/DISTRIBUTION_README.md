# LTCue

Windows 11 x64用のLTC同期映像プレイヤーです。

ZIPをすべて展開し、`LTCue.exe`を起動してください。.NETランタイムは同梱しています。FFmpeg/ffprobeとVisual C++ v14 x64ランタイムは別途必要です。

- [クイックスタート](docs/QUICKSTART.md)
- [操作リファレンス](docs/USER_GUIDE.md)
- [対応環境・動画形式](docs/COMPATIBILITY.md)
- [困ったとき](docs/TROUBLESHOOTING.md)
- [今回の変更と確認範囲](RELEASE_NOTES.md)
- [ライセンスについて](NOTICE.md)

実行に必要なDLL、`TestMedia`、`LICENSES`、`CorrespondingSource`は同梱したまま使用してください。`TestMedia`は起動時のテストショーで使用します。

開発手順、設計書、過去の記録は別配布の`source.zip`に収録しています。配布物とソースの対応は`MANIFEST.json`、ファイルのハッシュは配布ZIPと並ぶ`SHA256SUMS.txt`で確認できます。
