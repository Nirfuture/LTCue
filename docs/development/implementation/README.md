# 実装補足

[現行仕様](../FINAL_SPEC.md)の動作・制約を成立させるための責務、資源の寿命、非同期処理の採用・確定条件をまとめています。操作条件は現行仕様、試験の実行方法は[検証手順](../VERIFICATION.md)を参照してください。

各資料は「この資料について」で扱う範囲と参照する現行仕様を示し、全体の関係から処理の流れ、失敗・取消・競合、制約へ進みます。末尾に実装の参照先をまとめています。

| 資料 | 内容 |
|---|---|
| [操作の所有権と確定境界](OPERATION_ACCESS.md) | 手動・同期・出力の所有権、保存・編集・蓋絵変更の反映と取消 |
| [LTC設定の適用と復旧](LTC_SETTINGS.md) | 時計方針と補正の採用、入力切替の直列化、保存・復旧の順序 |
| [素材解析とHAP索引の管理](HAP_PREPARATION.md) | 解析の共有範囲、索引の対応条件、保管量・取消・無効化 |
| [素材障害の状態管理](PLAYBACK_ERRORS.md) | 失敗状態の伝達、素材世代、再検査と自動復旧の制限 |
| [映像の同期復旧](SYNC_RECOVERY.md) | 復旧開始条件、先行準備、資源制限、表示判定との関係 |
