# 困ったとき

## Windowsに起動をブロックされる

現在の配布版は未署名のため、Smart App Controlが有効な環境では起動をブロックされる場合があります。

## 起動しない

ZIPをすべて展開し、展開先の`LTCue.exe`から起動してください。

フォルダー内のファイルを移動・削除した場合は、ZIPを展開し直してください。

あわせて、Visual C++ x64ランタイムがインストールされているか確認してください。

## 動画を読み込めない

次を確認してください。

- 動画ファイルが移動・削除されていないか
- [対応する動画形式](COMPATIBILITY.md)か
- FFmpeg・ffprobeをPATHに登録しているか

一覧にエラーが表示されている場合は、「エラー」欄にマウスを重ねると内容を確認できます。

## LTCを受信できない

「設定」のLTC入力タブで、入力ピークが動くかと受信状態を確認し、次の項目を確認してください。

| 項目 | 確認すること |
|---|---|
| LTC入力 | 接続した入力機器を選んでいるか |
| 入力チャンネル | LTCが入っている側のLまたはRを選んでいるか |
| LTC形式 | 送信元のフレームレート・DF/NDFと一致しているか |

送信元の出力、ケーブル、入力機器の接続と入力レベルも確認してください。

画面左上が`--:--:--:--`の場合は、まだLTCを受信していません。表示が薄くなっている場合は、入力の喪失またはエラーが発生しています。

## 「出力開始」を押せない

ボタンの下に表示される理由を確認してください。

| 原因 | 対処 |
|---|---|
| キューがない | 動画を追加する |
| すべてのキューが無効 | 使用する行の「有効」にチェックを入れる |
| 開始TCが重複している | 開始TCを変更するか、不要な行を無効にする |
| 開始TCが不正 | 選択したLTC形式で入力できる値に直す |
| 動画にエラーがある | 一覧の「エラー」欄を確認する |
| 出力先が未接続 | ディスプレイを接続し、「映像出力」を選び直す |

## 黒画面になる

次の場合は黒画面になります。

- まだLTCを受信していない
- 最初の動画の開始TCより前
- 動画が終了し、次の動画が始まるまでの間

動画が表示されるはずの時刻でも黒い場合は、開始TC・動画の長さ・「有効」のチェックを確認してください。

## 蓋絵または黒い画面が出続ける

メイン画面の「蓋絵」欄を確認し、「映像に戻す」で解除してください。登録した画像を移動・削除した場合は「変更」から登録し直してください。

## 全画面出力が不安定になる

出力を停止して「設定」→「表示方式」を「互換（BitBlt）」に変更し、「適用」を押します。初期値は「標準（Flip）」です。現在の方式は設定画面で確認できます。

互換方式では負荷や表示遅延が変わる可能性があります。使用する環境で同期を確認してください。

## 映像が止まったままになる

LTC入力が途切れると、設定した補間時間の後に最後の映像を保持します。初期設定は0.1秒です。

タイムコード表示と、LTC入力機器の接続を確認してください。

## 音が出ない

音声出力は起動時OFFです。スピーカーボタンがON、音量が0より大きいことを確認してください。

- 設定の「音声出力」で選んだ機器とWindows側の音量を確認する。
- 音声形式がAAC・PCM系であることを確認する。
- 一時停止・停止・終端・LTC未受信/エラー・動画のない区間では無音になる。未受信でも手動再生中は音声を出せる。
- 機器切断などのエラー後は、接続を確認してスピーカーボタンをOFF→ONにする。

映像出力を開始するだけでは音声はONになりません。映像を止めても音声は継続するので、音声を止めたい場合はスピーカーボタンをOFFにします。

## プレビュー描画エラー・共通GPU描画エラー

プレビュー単独のエラーは、プレビュー情報欄に表示します。外部映像・音声の操作は継続できます。プレビューが動いている前提で判断せず、使用中の出力を確認してください。

共通GPUのエラーでは映像再生と外部映像を停止し、再生に追従する音声も無音になります。作業を保存してアプリを再起動してください。LTC入力監視は継続します。

## .NETの追加インストールを求められる

配布用ZIPはランタイム同梱です。まずZIPをすべて展開し直してください。開発用のbinフォルダーやDLL単体を、配布用ZIPの代わりに起動しないでください。

## 編集や設定変更ができない

映像出力中はキュー編集・LTC入力・映像設定を固定します。変更する場合は「出力停止」から停止してください。音声出力先は、音声をOFFにすれば設定できます。

## 前回のキューが表示されない

前回のキュー構成は自動で復元されません。「読込」から保存したJSONファイルを開いてください。

## 設定をリセットする

1. アプリを終了します。
2. `LTCue.exe`と同じフォルダーにある`phase2-settings.json`を別の名前に変更します。
3. アプリを起動し、入出力を設定し直します。

## ログを開く

エクスプローラーのアドレスバーに、次を入力します。

```text
%LOCALAPPDATA%\LtcPlayer\logs
```

ログには機器名や動画のパスが含まれる場合があります。共有する前に内容を確認してください。

ログは自動削除されません。1セッション8 MiB、合計256 MiBの記録上限に達すると追加の記録が止まります。不要な古いログは削除してください。

## 再生開始まで待たされる・音声が後から鳴り始める

開始時には素材解析、FFmpeg起動、復号などの準備が必要です。開始までの待ち時間と、再生開始後の位置ずれは別です。音声は準備後に現在位置へ合流します。

preview.11では停止後の映像の重複復号削減と、手動再生の映像・音声準備の並行化を行っています。preview.10には含まれません。検証環境Aでは素材を読まないFFmpeg起動にも待ちがあり、PC性能や特定の設定だけを原因とは断定していません。

## 映像・音声のずれが表示される

「○ms遅れ／先行」は、共通時計に対する内部の位置差が続いている状態です。「準備中」「再同期中」は開始・復旧の途中です。

「遅延なし」も物理画面・スピーカーでの遅延ゼロを示すものではありません。表示の意味は[操作リファレンス](USER_GUIDE.md#画面と同期表示)を参照してください。

## ディスプレイをつなぎ直しても外部出力が戻らない

preview.11では、出力先の切断・表示構成変更で外部出力を停止します。接続と設定の「映像出力」を確認し、「出力開始」で再開してください。別の画面へ自動で出力し直しません。

画面構成の変更で音声も一時的に途切れる場合があります。音声が戻らない場合は出力先を確認し、スピーカーボタンをOFF→ONにします。
